One line of awkward small talk between two robots in an elevator, 116 characters: **"I would offer you my charger, but we both know I would only do it to have something to say for the next nine floors."**

The polite offer is confessed mid-sentence to be a pretext — the robot only wants something to say for nine floors. Charging habit as machine logic, forced courtesy as the joke, loneliness as the thing neither robot names.

## Run it

```sh
node main.ts
```

The program writes the line to `/output/entry.txt` (or to `$OUTPUT_DIR/entry.txt`
for a local dry run).
